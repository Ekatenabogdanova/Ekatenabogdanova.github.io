# Сайт-портфолио Екатерины Богдановой

Статический сайт на GitHub Pages: https://ekatenabogdanova.github.io
Сборки нет — правишь HTML, коммитишь в `main`, через 1–2 минуты изменения на сайте.

## Страницы

- `index.html` — главная: шоукейс проектов, ссылки на кейсы
- `looma.html` — кейс Looma (чёрный + красный, Cormorant Garamond + Inter)
- `vidmer.html` — кейс Vidmer.dance: реальный сайт на Tilda (май 2024) + концепт редизайна 2026 года (чёрный/белый/#FF6600, Oswald + Onest; блок концепта тёмный, Jost)
- `frameup.html` — кейс Frame Up (афиши для @frameup_official и @high.heels_convention); внутри своя система токенов `--t-*`, `--ls-*`, `--gap-*`, `--w-*`, Montserrat + Lexend Zetta (только для латинских названий событий)
- `resume.html` — резюме (палитра главной, Playfair + Onest + PT Mono), PDF лежит рядом
- `r-9yzmnjieii/` — скрытая шпаргалка по проекту rockeroleg.ru: noindex, ни откуда не ссылается и не попадает в `sitemap.xml`
- `assets/` — картинки по проектам, `favicon.svg`, `og-cover.jpg`
- `llms.txt`, `robots.txt`, `sitemap.xml` — обновлять при добавлении или удалении публичной страницы

## Общая рамка всех кейсов

У каждого кейса свой визуальный стиль, его не надо перекрашивать в стиль главной. Связывает страницы только общая рамка:

- `.home-mark` — ссылка назад «● Е. Богданова» вверху (PT Mono 12px caps, letter-spacing .12em, точка #7E2625, стрелка при наведении). Стили лежат внутри самой страницы — для нового кейса копируй блок из существующего
- `.case-next` — финальная полоса со следующим проектом и кнопками «Все проекты / Резюме / Телеграм». Порядок по кругу: Looma → Vidmer → Frame Up → Looma. Новый кейс встраивается в этот круг
- `assets/favicon.svg` подключён на всех страницах

## Правила по содержанию

- Концепт Vidmer не запускался — никаких цифр результата, только метрики, которые предлагается измерять
- Картинки, сгенерированные ИИ, подписаны «сгенерировано»
- Из переписки с заказчиками Frame Up не публиковать имя ассистента, телефон, цену и оплату
- Цитаты в разделе «Задача» кейса Vidmer — иллюстративные, их нужно подтвердить или заменить

## Исходники вне репозитория

Концепт редизайна Vidmer (v5: `index.html`, `ds.css`, `ds.html`) делался отдельно, в репозиторий попали только скриншоты `assets/vidmer/v5-*.jpg`, `ds5-*.jpg` и `flow5.mp4`. Чтобы снять новые скриншоты, нужны исходники концепта

## Перед каждым пушем

Над сайтом могут работать несколько человек. Перед `git push`:

1. `git pull --rebase`
2. Проверить `git diff` своих изменений против `origin/main` на удалённые строки — бывало, что чужой коммит из устаревшей копии молча стирал блоки
3. Если пуш отклонён — снова `pull --rebase` и повторить
